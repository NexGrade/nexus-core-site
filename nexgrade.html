Horário escolar que se integra com o Estado, não contra ele.

NexGrade gera a grade horária da escola e resolve, de verdade, a exportação para o SEED-PR e o RCO — o ponto onde os sistemas mais usados no Paraná mais falham hoje.

Pedir demonstração
O problema

Escolas gastam horas corrigindo o que a integração deveria ter feito sozinha.

Nas escolas estaduais do Paraná, a montagem de horário concorre com um problema conhecido: sistemas que geram a grade mas não conseguem exportar para o RCO de forma confiável, deixando a integração com a SEED-PR por conta de retrabalho manual — correção de código de disciplina, matriz curricular divergente, formatos que não batem.

Integração nativa, não remendada

Código SAE, matriz curricular e composição curricular oficial (BNC, FGB, itinerários formativos) já nascem vinculados aos dados do SEED-PR — sem mapeamento manual depois.

Motor de geração configurável

Regras de geminação de aula, disponibilidade de professor e aulas fixas — com parâmetros nomeados de forma clara, não códigos de letra que só quem decorou entende.

Exportação para o RCO que funciona

Formato de arquivo, código INEP, duração de aula e seleção por turno seguindo exatamente o que o RCO espera receber.

Piloto sem custo

Toda escola nova começa no plano Piloto, gratuito, enquanto o NexGrade está em fase de validação com escolas parceiras.

TypeScript Node.js + Express Drizzle ORM PostgreSQL (Supabase) React + Vite Clerk (autenticação multi-tenant)
